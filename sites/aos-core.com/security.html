When to Rotate Keys

  • Every 90 Days: Standard security practice (set calendar reminder)
  • After Exposure: Pasted in chat, email, or accidentally committed to Git
  • Team Changes: When team members leave or roles change
  • Security Incidents: Any suspicious activity or breach
  • Provider Switch: Changing from OpenAI to Claude, etc.

Security Best Practices

⚠️ NEVER commit API keys to Git or paste them in plain text!

✅ DO:

  • Store keys in environment variables (Netlify, Vercel, Docker)
  • Enable "Keep secret" / "Encrypted" options
  • Use password manager for backup (1Password, Bitwarden)
  • Set billing limits at provider level
  • Monitor usage dashboards weekly
  • Use dated key names (e.g., "AOS-2026-01-02")

❌ DON'T:

  • Never put keys in code files or commit to Git
  • Never email or paste keys in chat
  • Never share same key across multiple projects
  • Never ignore billing alerts or suspicious usage
  • Never skip scheduled rotations
