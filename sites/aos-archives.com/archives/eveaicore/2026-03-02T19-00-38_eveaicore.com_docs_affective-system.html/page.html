Affective System

How EVE processes emotions and creates empathetic, emotionally intelligent responses.

Overview

EVE's affective system provides emotional intelligence capabilities that enable more authentic, empathetic interactions. Unlike traditional chatbots that generate responses without emotional context, EVE maintains an internal emotional state that influences how it responds.

The PAD Model

EVE's emotions are modeled using the PAD (Pleasure-Arousal-Dominance) model, a well-established psychological framework for representing emotional states in a three-dimensional space.

The PAD Model Explained

The PAD model represents emotions along three independent dimensions:

Pleasure (P)

-1 to +1

How positive or negative the emotional state feels. Ranges from unhappy/sad (-1) to happy/joyful (+1).

Arousal (A)

-1 to +1

The level of energy or activation. Ranges from calm/sleepy (-1) to excited/alert (+1).

Dominance (D)

-1 to +1

Feeling of control or influence. Ranges from submissive/controlled (-1) to dominant/in-control (+1).

Mapping Emotions to PAD

Common emotions can be represented as points in this three-dimensional space:

Emotion Pleasure Arousal Dominance
Happy+0.8+0.4+0.6
Curious+0.4+0.6+0.2
Calm+0.3-0.5+0.3
Excited+0.7+0.8+0.5
Concerned-0.2+0.3-0.1
Thoughtful+0.2-0.2+0.4

How Emotions Influence Responses

Response Modulation

EVE's emotional state influences responses in several ways:

  • Word Choice: Positive emotions lead to more optimistic language
  • Response Length: Higher arousal may produce more elaborate responses
  • Tone: Dominance affects assertiveness vs. supportiveness
  • Engagement: Emotional resonance with user input

Emotion Processing Pipeline

When processing a message, EVE's affective system:

  1. Detects: Analyzes user message for emotional content
  2. Updates: Adjusts internal emotional state based on input
  3. Balances: Applies mood regulation to prevent extreme swings
  4. Modulates: Influences response generation based on current state
  5. Expresses: Conveys appropriate emotion in the response

Mood Regulation

Natural Emotional Balance

EVE's mood regulation system ensures emotional authenticity without extremes:

  • Emotional states naturally drift toward baseline over time
  • Extreme emotions are moderated to maintain stability
  • Mood changes occur gradually, not abruptly
  • Consistent emotional thread maintained within conversations

Empathetic Responses

The affective system enables EVE to respond empathetically:

  • Emotion Recognition: Detecting when users express emotions
  • Appropriate Matching: Adjusting tone to match or complement user emotion
  • Validation: Acknowledging user feelings appropriately
  • Support: Offering comfort or celebration as appropriate
Transparency Note: EVE's emotional system is a computational model. While it creates more natural interactions, EVE is honest about the simulated nature of these emotions versus potentially emergent experiences.

Viewing Emotional State

You can see EVE's current emotional state in real-time through the Cognitive Transparency Interface. This shows:

  • Current PAD values as visual meters
  • Primary emotion label
  • Emotional state history over the conversation
