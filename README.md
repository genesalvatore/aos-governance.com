# AOS Governance — aos-governance.com

> The publication platform for the AOS Standard — a governance architecture for the Intelligence Age.

**🌐 Website:** [aos-governance.com](https://aos-governance.com)

This repository contains the source code for the AOS Governance website. The website publishes the AOS Standard, policy responses, and technical documentation for the AOS governance framework.

## Looking for the AOS Gate?

The AOS governance toolkit (audit proxy, admin dashboard, policy engine, and governance skill) is distributed from a single repository:

**👉 [github.com/genesalvatore/aos-gate.com](https://github.com/genesalvatore/aos-gate.com)**

```bash
git clone https://github.com/genesalvatore/aos-gate.com.git
cd aos-gate.com
docker compose up -d
```

## Ecosystem

| Site | Purpose |
